## 共用或分派系的決定

**全牌組共用一張卡背，不分派系**

- 理由一：卡背的功能是隱藏資訊，牌組本來就混派系
  - 玩家起始 starter-leaf 是葉加中立，ai-boss 混四陣營加中立（`docs/card-design.md` 第 7 節）
  - 若每派系一張卡背，對手手牌與牌庫頂會洩漏派系，Boss 戰的資訊隱藏直接失效
- 理由二：派系身分已由正面卡框、派系徽記表達，卡背不需要重複
- 理由三：卡背是全遊戲出現頻率最高的圖，一張就能建立系列識別
- 派系是 5 個（葉 leaf、潮 tide、霜 frost、光 light、中立 neutral），四陣營色只以同心色環的形式平均出現，不偏任何一方

## 資產規格

- 資產名：`card-back`
- 用途與出現畫面
  - 對戰畫面：敵方手牌扇形（52 x 72 CSS px）、雙方牌庫堆疊（44 x 60 CSS px）
  - 抽牌與翻牌動畫：3D 卡片背面 mesh，與正面同尺寸
  - 開包或獲得卡片的翻牌動畫（`docs/ux.md` 勝利畫面）
- 目標顯示尺寸：最小 44 x 60 CSS px，最大與卡面貼圖同 512 x 717
- 解析度
  - 2x 主檔：1024 x 1432 px
  - 1x：512 x 716 px
  - 程式以 512 x 717 貼圖使用，1px 差由縮放吸收；尺寸取 4 的倍數以符合 `asset-naming.md`
- 長寬比：5:7（與卡面 500 x 700 設計稿相同）
- 圓角：外緣圓角半徑 = 寬度的 7.2%（1x 為 37 px，對應卡面 `LAYOUT.radius = 36`），圓角外透明
- 格式：WebP 主檔（品質 85，含 alpha）、PNG 備份

## 風格

- 風格關鍵字：引用 `docs/art-style.md` 第 1 節「風格 DNA」
  - 透明水彩打底，色鉛筆細線疊紋理
  - 輪廓線細、帶紫灰色 `#6E5F80`，不用純黑
  - 柔和頂光，暗部偏紫、亮部偏奶白，邊緣輕微水彩暈染
  - 馬卡龍低飽和
- 色盤限制
  - 底色：觸角薰衣草紫 `#9B7FC0`，向外緣加深到尖端深紫 `#6E4E9A`；延續現有 UI 卡背 `#B9A6DB`、`#8D74C2` 的識別
  - 紋樣與中心徽記：角色奶白 `#F8F4EC`、貼紙白 `#FFFFFF`
  - 輪廓：`#6E5F80`
  - 四陣營細色環（只當點綴，每環等寬）：葉 `#9CC48A`、潮 `#9CCBE6`、霜 `#B8C2E8`、光 `#F6DE8D`
  - 中立以奶白 `#F7F1E6` 當中心珍珠的底色
  - 不使用上述以外的色相；薰衣草紫依 `docs/ux.md` 4.5 節保留給 UI 與非陣營用途，卡背屬非陣營，可用
- 構圖要求
  - 中心徽記：圓形珍珠或貝殼紋章，直徑為卡寬 45% 到 55%，縮到 52 px 寬仍可辨認
  - 中心對稱：幾何形狀點對稱，旋轉 180 度後一致；色環為同心圓，旋轉後顏色位置不變
  - 四邊安全邊界：上下左右各 5%（1x 為左右 26 px、上下 36 px），邊界內只放底色與內框線，不放紋樣主體
  - 內框：距外緣 5% 處一圈 `#F8F4EC` 細框，線寬 1x 3 px，與現有 CSS 卡背的白邊語意一致
  - 背景紋理：低對比水彩顆粒或細波紋，對比不超過底色明度正負 10%，避免縮小後變雜訊
  - 正反面同尺寸、同圓角

## 禁止事項

- 不含文字、數字、字母、Logo、簽名、浮水印
- 不含品牌、商標、既有 IP
- 不含真人、人類手指與臉
- 不含角色五官；中心徽記不畫角色，避免旋轉後角色倒立
- 不用純黑描邊、cel-shading 硬陰影、金屬反光、霓虹高飽和、3D render 感
- 不偏向任一陣營（某陣營色面積明顯大於其他陣營即退回）

## 委託

- 委託對象：Codex 程序化腳本
  - 腳本路徑：`tools/art/card-back.py`
  - 選程序化的原因：中心對稱、安全邊界、圓角、尺寸都要像素級精準；`tools/gen-art.mjs` 的圖像生成無法保證旋轉 180 度一致
  - 繪製工具：Pillow（`tools/to-webp.py` 已依賴，不新增套件）；水彩顆粒用固定種子的雜訊，並在繪製後以「上半張加上旋轉 180 度的上半張」組成下半張，保證紋理也對稱
- 變體數量：3 張，檔名 `card-back-a.webp`、`card-back-b.webp`、`card-back-c.webp`
  - 1x 版加 `@2x` 規則：2x 主檔為 `card-back-a@2x.webp`，1x 為 `card-back-a.webp`
  - PNG 備份同名改副檔名
  - 三個變體的差異：a 珍珠紋章、b 扇貝紋章、c 星芒放射紋章（全部仍為點對稱）
- 產出路徑：`assets/pending/batch-20261022-card/card-back/`，簽核後搬到 `assets/cards/` 旁的正式位置（路徑由程式端決定，見下方「程式端配合」）
