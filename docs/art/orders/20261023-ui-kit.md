## 共通規格

**比照已上線的卡框切片：1x 與 @2x、WebP 與 PNG、透明背景，九宮格安全區以 1x 標註**

- 格式
  - WebP 主檔（品質 85，`exact` 保留透明像素色）與 PNG 備份
  - 1x 為 CSS 像素尺寸，@2x 為兩倍；程式一律用 @2x 當 `border-image-source`，以 `border-image-width` 指定 1x 寬度
- 透明背景：四角 alpha 為 0；例外為 `minion-window-*`、`slider-*`、`title-underlay-*`（形狀貼齊畫布邊）
- 命名：小寫 kebab-case、`<家族>-<子項>-<變體>`，2x 加 `@2x`，與 `asset-naming` 慣例一致（例：`btn-primary-a-hover@2x.webp`）
- 變體：每項 a、b 兩款
  - a 柔和水彩：線條少、邊緣柔，最接近已選用的卡框 a 套
  - b 色鉛筆裝飾：描邊排線明顯，兩端多一個小裝飾
- 風格參考圖（`-i` 帶入 Codex）
  - `assets/_source/portraits/xiaoye.png`（角色畫風）
  - `_refs/ref-icons.png`（已上線四角圖示：費用、攻擊、生命、葉派系）
  - `_refs/ref-card-frame-leaf.png`（已上線卡框 a 套）
  - `_refs/ref-bg-battle.png`（已上線對戰背景 landscape-b）
- 共通禁止
  - 文字、字母、數字、Logo、浮水印、五官
  - 純黑描邊、金屬反光、塑膠亮面、3D render 感、霓虹色
  - 漂浮感構圖：傾斜、動態線、飛散亮點；所有素材都是靜態
- 動態規則（給程式端）：只能用透明度、亮度、光暈；按下可下沉 1 到 2px；嚴禁待機上下浮動、呼吸縮放、搖擺

## A 按鈕設計系統

**主色取對戰「結束回合」實際色 `#7A64B0`（`BattleScreen.vue` `.end-turn`），與全域 `.btn` 同色；四種狀態由同一張原圖導出，色相不漂移**

- 狀態導出規則（`tools/art/ui-kit.py` 的 `states()`）
  - hover：亮度 +7%
  - pressed：亮度 -8%，整體下移 2px（1x）
  - disabled：去飽和到 15%，混入 `#E4DFEA` 42%，透明度 90%
- 切片
  - `btn-primary-<變體>[-hover|-pressed|-disabled]`：主要按鈕，填色 `#7A64B0`，下緣厚度 `#5E4C94`
    - 1x 240 x 64，九宮格左右各 32、上下 0
  - `btn-secondary-<變體>[...]`：次要按鈕，奶白 `#FFFDF7`，下緣 `#E2D8C8`
    - 1x 240 x 64，九宮格左右各 32
  - `btn-danger-<變體>[...]`：危險按鈕（放棄對戰），`#B04A6A`，下緣 `#8A3852`
    - 1x 240 x 64，九宮格左右各 32
  - `btn-icon-<變體>[...]`：圓形圖示按鈕底（齒輪、關閉、返回），1x 64 x 64，不拉伸
  - `menu-item-<變體>[...]`：主選單按鈕外框，左端貝殼與海草小裝飾
    - 1x 440 x 96，九宮格左 88、右 48、上下 0
    - 鎖定狀態用 `-disabled`，再由程式疊 `lock` 圖示與說明文字
- 驗收：九宮格拉到 120 到 480 寬，兩端裝飾不變形；白字或深字放在中段，對比依 `docs/ux-buttons.md`

## C 共用標題組

**前綴、底飾、分隔線三件可自由組合，套到主選單、劇情地圖、收藏、設定、結算的標題**

- `title-prefix-<造型>-<配色>-<變體>`：標題前綴裝飾
  - 造型：`leaf` 葉片、`shell` 貝殼、`star` 海星
  - 配色：`base` 通用（薰衣草紫、奶白、粉）、`leaf`、`tide`、`frost`、`light`
  - 1x 64 x 64（顯示 48 到 64），不拉伸；3 造型 x 5 配色 x 2 變體共 30 張
  - 小葉觸角剪影與泡泡串未出：觸角剪影容易被看成角色局部，泡泡串與背景上升泡泡語意重複，列在簽核頁「未出項目」
- `title-underlay-lg-<變體>`：頁面主標的水彩刷痕底
  - 1x 560 x 96，九宮格左右各 115，中段可拉伸；不加白邊
- `title-underlay-sm-<變體>`：區塊小標的標籤底
  - 1x 280 x 60，九宮格左右各 30
- `divider-pearl-<變體>`、`divider-seaweed-<變體>`：分隔線與標題底線
  - 1x 96 x 24，`background-repeat: repeat-x` 無縫平鋪
  - Codex 只出單一裝飾單元，底線與拼接由程式化腳本合成，保證週期等於寬度
- 建議組合
  - 主選單：`shell-base` + `underlay-lg` + `divider-pearl`
  - 劇情地圖：`leaf-base` + `underlay-lg` + `divider-seaweed`；章節標題 `underlay-sm` + 該章敵方陣營配色
  - 收藏：`leaf-leaf` + `underlay-lg`；分頁標籤 `underlay-sm`
  - 設定：`star-base` + `underlay-sm`，標題下 `divider-seaweed`
  - 結算：`ribbon` 當主標，下方 `divider-pearl`
