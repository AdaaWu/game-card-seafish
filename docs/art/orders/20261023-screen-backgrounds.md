# 美術素材委託單 bg-screens

- 流程見 `game-workflow/standards/placeholder-assets.md` 的「外部 AI 工具產出正式素材的流程」
- 日期：2026-10-23
- 填寫：art-director
- 批次：`batch-20261023-screens`
- 一張委託單涵蓋 5 個畫面背景，同一系列、同一規格，拆單反而難以對齊風格

## 現況

**對戰背景已選定 `bg-battle-*-b` 並上線，其他非對戰畫面沒有專屬背景**

- 上線檔：`assets/backgrounds/bg-battle-landscape.webp`、`bg-battle-portrait.webp`，與 `assets/pending/batch-20261022-card/battle-bg/bg-battle-*-b.webp` 逐位元相同
- 使用者喜歡對戰背景，本批以它為系列基準：珊瑚偏多、偏暖、水彩色鉛筆質感、中央低對比、沒有生物主體
- 對戰背景的已知問題：上 12% 有搶眼的水面波光與光束，本批要避開

## 資產規格

- 資產名與畫面
  - `bg-title`：標題畫面。暖光礁全景，系列中最有氣勢；中上方留給標題字
  - `bg-menu`：主選單。光合事務所所在的珊瑚礁街區，日常、溫暖
  - `bg-story`：劇情章節地圖。俯瞰的海底地形，隱約分出潮（淡藍青）、霜（冰白薰衣草）、光（鵝黃暖金）三區；中央留給關卡節點
  - `bg-deck`：收藏與牌組。海底貝殼收藏室或珊瑚圖書館；四周有細節，中央乾淨，會鋪滿卡片
  - `bg-picker`：自由對戰選對手。海底競技場入口或休息區
- 題材依 `docs/story.md`「世界觀」：同一座暖光礁裡的不同地點
  - 章節順序：潮（迷路的洋流）、霜（礁外深谷）、光（礁頂星光祭）
  - 地圖區域排列：橫式由左到右潮、霜、光；直式由下到上潮、霜、光（由淺到礁頂）
- 解析度：橫式 1920 x 1080、直式 1080 x 1920，最終尺寸，不提供 2x
- 格式：WebP 主檔品質 85，PNG 母檔留在 pending；單張 2MB 以內
- 變體：每個畫面每個方向 a、b 兩張，共 20 張

## 風格

- 基準：與對戰背景同一系列、同一畫家、同一光線與色調
  - 透明水彩薄塗加色鉛筆斜紋與紙張顆粒
  - 紫灰細描邊 `#6E5F80`，沒有黑線
  - 左上柔和漫射光，暗部偏薰衣草紫
  - 低飽和馬卡龍色；邊緣珊瑚偏多，奶白與杏色暖亮部
  - 主調：上 `#E4F4F1`、中 `#C6E4EE`、`#B3D2E8`、下 `#C8C1E6`，奶白 `#F8F4EC`
- 陣營色引用 `docs/art-style.md` 第 2 節
  - 潮 `#9CCBE6`、`#9EDBD2`；霜 `#EEF3FA`、`#B8C2E8`、`#CFC4D9`；光 `#F6DE8D`、`#E8C27A`、`#F5C9A0`；葉 `#9CC48A`
- 構圖：中央與 UI 覆蓋區低對比、低細節，細節集中在左右邊緣與四角
  - 通用中央區：橫式 x 20% 到 80%、y 25% 到 75%；直式 x 10% 到 90%、y 28% 到 72%
  - title 另加標題區：橫式 x 25% 到 75%、y 12% 到 45%；直式 x 10% 到 90%、y 12% 到 40%
  - story 中央區放寬：橫式 x 15% 到 85%、y 20% 到 80%；直式 x 10% 到 90%、y 18% 到 82%
  - deck 中央區放寬：橫式 x 15% 到 85%、y 18% 到 85%；直式 x 8% 到 92%、y 15% 到 85%
  - 上下各 12% 低細節，不畫海面、不畫水面波光

## 禁止事項

- 不含文字、數字、字母、Logo、招牌字、地圖標籤、浮水印
- 不含角色、生物主體、五官、真人
- 不含強烈明暗的光束（god rays）與搶眼的水面波光
- 不畫看起來會漂浮的主體：浮島、浮石、懸空物件、中央大氣泡；所有物件都要著地或貼著礁石
- 不用純黑描邊、cel-shading、金屬反光、霓虹色、3D render 感

## 委託

- 委託對象：Codex CLI 0.162.1 內建圖像生成
- 腳本：`tools/art/gen-screen-bg.mjs`（沿用 `gen-card-batch.mjs` 結構，並行度 3，偵測到配額或速率限制即停）
- 參考圖：每張固定附 2 張
  - 對戰背景同方向的 b：`assets/pending/batch-20261022-card/battle-bg/bg-battle-<方向>-b.png`
  - 筆觸與色彩參考：`assets/_source/portraits/xiaoye.png`（提示詞明寫不要畫出角色）
- 提示詞組成：開頭指令句、系列風格句、Subject、色調句、構圖句、限制句、變體句、禁止後綴
  - 變體 a：構圖較開闊，細節更往邊緣推
  - 變體 b：邊緣珊瑚較多，奶白與杏色略暖（最接近對戰背景 b）
  - 全文逐張記錄在 `assets/pending/batch-20261023-screens/prompts.md`
- 後製：`tools/art/post-screen-bg.py`（cover 裁切、LANCZOS、WebP q85 method 6，超過 2MB 才降 q80）
- 檢查：`tools/art/check-screen-bg.py`
  - 全圖、中央區、標題區的亮度標準差
  - 上下 12% 的亮度標準差與波光比例（亮度高於局部模糊 12 以上的像素比例）
  - 與對戰背景 b 的平均色、飽和度、冷暖差
- 產出：`assets/pending/batch-20261023-screens/`；選用圖複製到 `assets/backgrounds/bg-<畫面>-<方向>.webp`
